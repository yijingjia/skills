# Underlying_Logic_Systematic_Decision

> 基于《底层逻辑 看清这个世界的底牌（拥有看透世界的底牌，启动“开挂”的人生。“5分钟商学院”背后的思维方式）》提取

## 技能描述 (Description)
基于底层逻辑原则，通过区分事实与立场、分析时空因果、权衡选择代价、坚持长期主义及优化系统模型，进行系统化决策与问题解决。

## 适用场景 (When to Use)
- 面对复杂决策需要权衡利弊时
- 分析问题根源而非表面现象时
- 涉及多方博弈或利益交换时
- 制定长期战略而非短期应对时
- 设计制度或流程以解决根本问题时
- 在变革时代分析商业模式交易结构时

## 核心思维步骤 (Thinking Steps)

> Agent 必须严格按照以下步骤执行分析框架：

1. **区分输入信息是事实、观点还是立场，避免被立场误导判断。**
   - *详情*: 事实是客观存在，观点是看法，立场受利益影响。
   - 📖 *依据 (Chapter 8)*: 事实是最不容易产生争议的客观存在；观点是你对一个事实的看法；立场是被位置和利益影响的观点。

2. **在因果分析中加入时间轴，警惕滞后效应导致的判断失误。**
   - *详情*: 原因和结果可能在时空上远离，需给万事万物加上时间轴。
   - 📖 *依据 (Chapter 12)*: 滞后效应会让原因和结果在时空上远离，从而误导判断。

3. **明确选择意味着放弃，列出为获得当前选项必须承担的损失或放弃的其他路径。**
   - *详情*: 选择一个，放弃其他，勇敢选择后享受好处并承担坏处。
   - 📖 *依据 (Chapter 6)*: 学会选择，常常就是学会放弃：选择一个，放弃其他。

4. **评估决策是否符合长期价值，在涉及他人的决策中追求全局最优而非局部最优。**
   - *详情*: 定力即长期主义，博弈论强调全局最优和达成共赢。
   - 📖 *依据 (Chapter 6)*: 定力即长期主义，一切围绕长期价值展开。

5. **尝试改变系统模型或流程而非仅改变结果，寻找根本解。**
   - *详情*: 改变流程、制度是管理，改变系统、模型是治理。
   - 📖 *依据 (Chapter 13)*: 普通的人改变结果，优秀的人改变原因，顶级优秀的人改变模型。
