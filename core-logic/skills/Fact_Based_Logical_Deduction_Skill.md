# Fact_Based_Logical_Deduction_Skill

> 基于《底层逻辑 看清这个世界的底牌（拥有看透世界的底牌，启动“开挂”的人生。“5分钟商学院”背后的思维方式）》提取

## 技能描述 (Description)
基于事实与逻辑原理，通过追溯定义、验证证据、动态分析来探究事物根本原因的技能。

## 适用场景 (When to Use)
- 开会讨论解决问题时
- 需要验证假设得出结论时
- 需要证明某事物存在时
- 面对共识谬误时
- 探究事情真相
- 分析生活现象时
- 学习新概念时
- 个人成长与思维升级

## 核心思维步骤 (Thinking Steps)

> Agent 必须严格按照以下步骤执行分析框架：

1. **追溯核心概念的定义和历史以理清脉络，不满足于表面解释。**
   - *详情*: 遇到事情不满足于表面解释，不断地往下追溯，找到根本原因。
   - 📖 *依据 (14)*: 逻辑思维需要刨根问底，追溯定义和历史以理清脉络。

2. **要求提供钢铁般的证据来证明存在，避免用共识代替真理。**
   - *详情*: 证明存在需举出钢铁般的证据，得出一般性结论需靠逻辑推理证明。
   - 📖 *依据 (14)*: 证明存在需举出钢铁般的证据

3. **基于事实大胆假设，小心求证后得出结论并调整。**
   - *详情*: 从事实出发，对事不对人，不要被利益、立场左右。
   - 📖 *依据 (11)*: 假设—验证—结论—调整

4. **用动态的眼光看待问题，关注长期积累效应而非瞬间认可。**
   - *详情*: 结果是长期积累效应造成的，从宏观一直追溯（求导）到微观找到问题根源。
   - 📖 *依据 (17)*: 微积分思维方式：用动态的眼光看问题，结果是长期积累效应造成的。

5. **保持思维闭环开放，不断复盘进行结构调整以避免阴谋论。**
   - *详情*: 思维闭环永远开放，螺旋式延伸；离事实越远，离阴谋论就越近。
   - 📖 *依据 (14)*: 思维闭环永远开放，螺旋式延伸；离事实越远，离阴谋论就越近。
