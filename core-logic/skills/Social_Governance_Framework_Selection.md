# Social_Governance_Framework_Selection

> 基于《底层逻辑 看清这个世界的底牌（拥有看透世界的底牌，启动“开挂”的人生。“5分钟商学院”背后的思维方式）》提取

## 技能描述 (Description)
基于人性、道德、法律及族群/普遍法则的层级关系，分析当前交互场景的本质，选择最合适的协作规则或生存策略。

## 适用场景 (When to Use)
- 分析个体行为动机与社会规范本质
- 判断行为性质（人性/道德/法律）及边界
- 制定社会规则、公司制度或责权利体系
- 组织内外的沟通协作与价值交换
- 生存危机或无法讲理时的自我保护
- 跨越不同族群或组织的合作场景

## 核心思维步骤 (Thinking Steps)

> Agent 必须严格按照以下步骤执行分析框架：

1. **判断当前情境是否涉及生存和繁衍本能，或是属于群体协作规范。**
   - *详情*: 区分行为是源于无善无恶的人性本能，还是为了群体繁荣形成的道德规范。
   - 📖 *依据 (5)*: 人性只涉及生存和繁衍且无善无恶，道德是为群体繁荣形成的约定俗成规范。

2. **界定行为性质，区分是无人性、不道德还是触犯法律。**
   - *详情*: 确认法律是道德的底线子集，道德是反人性的社会契约，人性来自自私的基因。
   - 📖 *依据 (5)*: 法律是道德的子集，是维护群体存在的道德底线；道德是为了群体繁荣共同达成的社会契约，常常是反人性的；人性来自自私的基因。

3. **根据协作范围选择法则，用族群法则或普遍法则进行价值交换，必要时用自然法则保护自己。**
   - *详情*: 在组织内遵守族群法则，在组织间使用普遍法则，在生存受威胁时启用自然法则。
   - 📖 *依据 (34)*: 用族群法则、普遍法则和世界进行价值交换，在必要的时候，用自然法则来保护自己

4. **若处于组织内部，设置责权利并基于公理推演制度安排。**
   - *触发条件*: 当场景涉及公司管理或制度设计时
   - *详情*: 确保创造最大价值的人获得最大的收益，若制度违背公理则修改制度。
   - 📖 *依据 (17)*: 公司公理体系：创造最大价值的人，获得最大的收益。公理是一种选择、共识、基准原则。

5. **采用宣传舆论等长效引导方法，或惩罚驱逐等立竿影的约束方法。**
   - *详情*: 根据道德与法律的约束机制，选择引导或惩罚手段以实现群体繁荣。
   - 📖 *依据 (5)*: 采用宣传、舆论等长效引导方法，采用惩罚、驱逐等立竿影的约束方法
