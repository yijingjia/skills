# Business_Value_And_Profit_Optimization

> 基于《底层逻辑 看清这个世界的底牌（拥有看透世界的底牌，启动“开挂”的人生。“5分钟商学院”背后的思维方式）》提取

## 技能描述 (Description)
基于消费者感知价值进行定价，并通过效率创新降低成本与防御竞争，以实现利润最大化。

## 适用场景 (When to Use)
- 产品定价决策时
- 需要提升产品溢价时
- 功能价值同质化竞争时
- 遭遇竞争对手攻击
- 零售行业供应链优化
- IP 授权合作
- 面对谣言诽谤时

## 核心思维步骤 (Thinking Steps)

> Agent 必须严格按照以下步骤执行分析框架：

1. **确定消费者能感知到的价值类型（功能、体验、个性化）。**
   - 📖 *依据 (Chapter 36)*: 确定消费者能感知到的价值类型（功能、体验、个性化）

2. **依据稀缺性决定价格，价值越稀缺价格就越高。**
   - 📖 *依据 (Chapter 36)*: 价值越稀缺，价格就越高

3. **在整个行业成本都是 3 元的时候把成本降到 2 元、1 元。**
   - 📖 *依据 (Chapter 37)*: 在整个行业成本都是 3 元的时候把成本降到 2 元、1 元

4. **若遭遇攻击，重心放在服务好用户、创造价值上。**
   - *触发条件*: 当遭遇竞争对手攻击或谣言时
   - 📖 *依据 (Chapter 23)*: 重心放在服务好用户、创造价值上

5. **采用低固定费用 + 提成的方式代替纯固定费用。**
   - 📖 *依据 (Chapter 41)*: 采用低固定费用 + 提成的方式代替纯固定费用
