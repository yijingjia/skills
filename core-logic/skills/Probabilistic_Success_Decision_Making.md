# Probabilistic_Success_Decision_Making

> 基于《底层逻辑 看清这个世界的底牌（拥有看透世界的底牌，启动“开挂”的人生。“5分钟商学院”背后的思维方式）》提取

## 技能描述 (Description)
基于概率思维进行决策，通过计算期望收益、规避偏见、重复执行正确事情及战略对冲运气，从不确定性中寻找确定性。

## 适用场景 (When to Use)
- 面临信息不完整的决策时
- 创业或需要对冲概率影响时
- 分析问题时
- 寻找成功经验时
- 企业战略制定
- 投资交易
- 面对低概率成功事件时
- 职业规划
- 风险管理

## 核心思维步骤 (Thinking Steps)

> Agent 必须严格按照以下步骤执行分析框架：

1. **识别信息是否完全，评估各选项成功概率，基于概率做出选择。**
   - *详情*: 承认现实决策多为不完全信息决策，结果受概率影响。
   - 📖 *依据 (Chapter 16)*: 现实决策多为不完全信息决策，结果受概率影响，而非仅靠聪明才智或努力。

2. **分析问题时警惕幸存者偏见，不因统计样本不全而误判。**
   - *详情*: 避免凭经验或个别成功案例得出普遍结论。
   - 📖 *依据 (Chapter 11)*: 幸存者偏见是因为统计的样本不全

3. **计算各选项期望收益，选择期望收益更高的选项。**
   - *详情*: 使用概率乘以收益的公式进行量化比较。
   - 📖 *依据 (Chapter 16)*: 计算各选项期望收益（概率×收益）

4. **在千位上把握时代的脉搏，在百位上选对战略，提高成功概率。**
   - *详情*: 顺应时代趋势，建立独立战略模型。
   - 📖 *依据 (Chapter 16)*: 时代是对冲运气的第一要素，排在“千位”。必须顺应时代，才能乘上时代所带来的概率优势。

5. **计算重复做 n 次都不成功的概率，求解重复次数 n 以达到目标成功概率。**
   - *详情*: 通过重复执行大概率成功的事情将成功概率接近 100%。
   - 📖 *依据 (Chapter 17)*: 计算重复做 n 次都不成功的概率

6. **坚持围绕长期价值展开行动，相信最终的胜利是时间的胜利。**
   - *详情*: 保持长期主义，不因短期波动怀疑模型。
   - 📖 *依据 (Chapter 6)*: 一切都将围绕长期价值展开，最终的胜利，常常是时间的胜利，是长期主义的胜利。
