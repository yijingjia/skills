# Strategic_Leverage_And_Momentum_Application

> 基于《底层逻辑 看清这个世界的底牌（拥有看透世界的底牌，启动“开挂”的人生。“5分钟商学院”背后的思维方式）》提取

## 技能描述 (Description)
基于杠杆与势能理论，指导 Agent 如何通过能力积累、杠杆选择及势能构建来实现指数级成长或战略突破。

## 适用场景 (When to Use)
- 想要超越个人边界获得巨大成功时
- 企业构建商业竞争壁垒或制定战略时
- 需要规模化复制专业能力或业务时
- 希望公司拥有不受限制的发展空间时
- 需要突破自身能量限制实现突破时
- 规划个人职业发展路径或分析成功逻辑时

## 核心思维步骤 (Thinking Steps)

> Agent 必须严格按照以下步骤执行分析框架：

1. **评估当前核心能力与效率基准，确认是否已具备获得能力的能力。**
   - *详情*: 分析现有商业模式中的能力与效率因子，确定是否需要通过加班或学习先夯实内核。
   - 📖 *依据 (19)*: 人生商业模式=能力×效率×杠杆。一个人最重要的能力，是获得能力的能力。

2. **识别并选择适合的杠杆类型，包括团队、产品、资本或影响力。**
   - *详情*: 根据业务属性判断是依赖团队复制、产品化转化、资本收购还是影响力扩散。
   - 📖 *依据 (19)*: 借助杠杆（团队、产品、资本、影响力）

3. **寻找战略势能，关注技术的领先、商业模式的优越以及效率的优势。**
   - *详情*: 避免单纯依赖员工化学能，转而寻找外在势能如技术壁垒或商业模式优势。
   - 📖 *依据 (35)*: 寻找战略势能（技术的领先、商业模式的优越以及效率的优势）

4. **制定长期计划用时间去累积能量，如建立研发壁垒或知识库。**
   - *详情*: 投入资源构建如水坝般的能量壁垒，包括研发费用投入或知识库方法论沉淀。
   - 📖 *依据 (35)*: 用时间去累积能量（如建水坝）

5. **在壁垒建立后打开水闸，充分释放势能或通过资本杠杆出售获利。**
   - *详情*: 当能量累积到临界点或公司价值大幅增加后，执行释放动作以实现最大收益。
   - 📖 *依据 (35)*: 打开水闸充分释放势能
