# Boundary_Ownership_Execution

> 基于《底层逻辑 看清这个世界的底牌（拥有看透世界的底牌，启动“开挂”的人生。“5分钟商学院”背后的思维方式）》提取

## 技能描述 (Description)
基于所有权认知识别人际边界，在职场与社交中正确行使权利并尊重他人隐私与决策。

## 适用场景 (When to Use)
- 职场上下级沟通
- 公司会议决策
- 人际交往中涉及个人隐私
- 社交场合遇到隐私询问
- 判断行为是否越界

## 核心思维步骤 (Thinking Steps)

> Agent 必须严格按照以下步骤执行分析框架：

1. **分析当前情境中时间、隐私或权利的所有权归属。**
   - *详情*: 确认什么是你的，什么是他的。
   - 📖 *依据 (32)*: 边界感的本质，是对所有权的认知。

2. **分清各自权利，确认建议权与决策权的归属。**
   - *详情*: 参与讨论发表建议，但明确决定权归属。
   - 📖 *依据 (32)*: 发表建议是员工权利，做决定是老板权利。

3. **充分发表意见后坚决执行决定，表达观点但不强迫对方接受。**
   - *详情*: 保留自己的看法，但执行老板的命令。
   - 📖 *依据 (32)*: 充分发表意见后坚决执行决定

4. **保护个人隐私并不越界干涉他人，越界前先征得对方同意。**
   - *详情*: 隐私的所有权属于自己，别人不应该主动询问。
   - 📖 *依据 (32)*: 个人决策（如婚姻）和隐私（如收入）属于个人所有权，他人不应越界干涉。
