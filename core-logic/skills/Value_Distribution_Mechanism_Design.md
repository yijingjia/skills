# Value_Distribution_Mechanism_Design

> 基于《底层逻辑 看清这个世界的底牌（拥有看透世界的底牌，启动“开挂”的人生。“5分钟商学院”背后的思维方式）》提取

## 技能描述 (Description)
基于竞争优势、项目阶段与交易成本，设计固定、剩余或分成的利益分配方案，以平衡效率与公平。

## 适用场景 (When to Use)
- 设计薪酬体系与合伙人关系
- 不确定项目的利润分成谈判
- 合作双方存在竞争优势差异时
- 项目处于不同盈利发展阶段

## 核心思维步骤 (Thinking Steps)

> Agent 必须严格按照以下步骤执行分析框架：

1. **确定利益分配形式以定义共同体层级，选择工资、奖金、股权或价值观支付。**
   - *详情*: 工资支付给责任，奖金支付给超额业绩，股权支付给未来的潜力，价值观支付给共同梦想。
   - 📖 *依据 (27)*: 利益分配形式决定共同体层级。

2. **判断合作双方的核心竞争力，确定谁掌握稀缺资源。**
   - *详情*: 掌握稀缺资源、具有核心竞争力的一方应拿劣后（剩余利润），无核心竞争力的一方拿固定。
   - 📖 *依据 (41)*: 合作中，掌握稀缺资源、具有核心竞争力的一方应拿劣后（剩余利润），无核心竞争力的一方拿固定。

3. **评估项目所处的发展阶段，设定人力与资本的优先劣后关系。**
   - *详情*: 辛苦赚钱阶段人力优先，资本收益及超出预期阶段资本优先，均衡阶段人力资本均衡分配。
   - 📖 *依据 (41)*: 不确定项目中，不同利润阶段对应不同的优先劣后分配方式。辛苦赚钱阶段人力优先；资本收益及超出预期阶段资本优先

4. **评估合作中的交易成本，决定是否引入分成机制增加劣后激励。**
   - *详情*: 交易成本高时，需引入分成机制增加劣后激励，竞争优势大的一方通常拿剩余。
   - 📖 *依据 (41)*: 合作中谁拿固定、谁拿剩余、谁拿分成取决于竞争优势和交易成本。

5. **验证分配方案是否在初次分配中寻求了效率与公平的均衡。**
   - *详情*: 避免垄断和资本无序扩张伤害了初次分配中效率和公平的均衡。
   - 📖 *依据 (44)*: 效率与公平的均衡。在初次分配时，也要寻求“效率与公平的均衡”。
