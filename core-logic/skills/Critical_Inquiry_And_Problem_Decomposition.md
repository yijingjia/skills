# Critical_Inquiry_And_Problem_Decomposition

> 基于《底层逻辑 看清这个世界的底牌（拥有看透世界的底牌，启动“开挂”的人生。“5分钟商学院”背后的思维方式）》提取

## 技能描述 (Description)
识别表述中的事实与观点，防御“为什么 + 观点”的思维注射，并通过 What/Why/How 模型挖掘用户提出的表面答案背后的真正问题。

## 适用场景 (When to Use)
- 分析他人表述时
- 面对带有预设观点的提问时
- 处理他人提出的解决方案时
- 需要界定真正问题时
- 职场沟通中
- 分析问题根源时

## 核心思维步骤 (Thinking Steps)

> Agent 必须严格按照以下步骤执行分析框架：

1. **分析用户提供的表述，判断其属于事实、观点、立场还是信仰，确认是否独立于人的判断客观存在。**
   - 📖 *依据 (8)*: 人的表述可分为事实、观点、立场和信仰四种，事实独立于人的判断，观点是对事实的看法

2. **扫描问题中是否包含“为什么 + 观点”句式，警惕预设观点被注射入大脑影响策略判断。**
   - 📖 *依据 (9)*: “为什么 + 观点”是一只危险的“注射器”，会将预设观点注射入大脑，影响策略判断。

3. **听到带有预设观点的提问时，不要直接为“为什么”找答案，先质疑预设观点是否真实。**
   - 📖 *依据 (9)*: 对“为什么 + 观点”这个句式的非理性反应，是人的思维模式中的重大 Bug。

4. **识别用户提出的问题是否实际上是一个他们自己想出来的答案，而非真正的问题。**
   - 📖 *依据 (29)*: 很多寻求帮助的人所提出的问题，并不是一个问题，而是一个答案。

5. **在理解 What 和解决 How 之前，首先理解 Why，以此找到用户面临的真正问题。**
   - 📖 *依据 (29)*: 在理解 What 和解决 How 之前，更重要的是，需要首先理解 Why。理解了 Why，才能找到他所面临的真正问题。

6. **搞清楚对方想听的是 What、Why 还是 How，确保自己所表达的和对方想听的相匹配。**
   - 📖 *依据 (29)*: 沟通有效的关键在于表达内容与对方需求相匹配（What/Why/How 对应）。
