# System_Structure_Analysis

> 基于《底层逻辑 看清这个世界的底牌（拥有看透世界的底牌，启动“开挂”的人生。“5分钟商学院”背后的思维方式）》提取

## 技能描述 (Description)
透过表象识别系统要素与连接关系，通过改变系统结构从根本上解决问题。

## 适用场景 (When to Use)
- 遇到问题需要寻找解决方案时
- 理解表象背后的系统时
- 系统出问题或规律失效时
- 需要从根本上解决系统性问题时
- 认清当下处境或理解时代变革

## 核心思维步骤 (Thinking Steps)

> Agent 必须严格按照以下步骤执行分析框架：

1. **识别当前问题背后的表象规律，确认系统是否出问题导致规律失效。**
   - 📖 *依据 (12)*: 每一个表象背后都有一个“黑盒子”（系统），它是所有规律产生的原因；系统出问题规律就失效。

2. **列出系统中所有看得见的要素，区分要素与要素之间的关系。**
   - 📖 *依据 (18)*: 要素，是系统中你看得见的东西；关系，是系统中你看不见的、要素之间相互作用的规律。

3. **分析要素之间的连接关系，定位问题解决方案隐藏的连接点。**
   - 📖 *依据 (12)*: 系统=要素×连接关系；问题的解决方案常常藏在要素之间的连接关系里。

4. **拆解系统基础模块，识别变量、因果链、增强回路、调节回路和滞后效应。**
   - 📖 *依据 (12)*: 复杂系统由五种基础模块搭建而成：变量、因果链、增强回路、调节回路和滞后效应。变量随时间变化呈现存量和流量两种状态。

5. **打开系统黑盒子，研究各个组成部分之间的关系以拥有全局之眼。**
   - 📖 *依据 (13)*: 系统是若干部分相互联系、相互作用形成的具有某些功能的整体。企业家要拥有全局之眼，从系统角度看待问题。

6. **设计改变模型或系统的治理方案，而非单纯监督结果。**
   - 📖 *依据 (13)*: 顶级优秀的人用治理的方式管理组织。解决问题的最有效办法是用洞察力改变模型、改变系统。
