# templates/

此目录用于辅助 `core-logic` 首次分析输出的格式一致性。

## 推荐追加小节（与主调度「输出格式强约束」一致）

每次首次分析必须在末尾追加：**分析所依据的书内章节与理论**。

### 1. 小节标题
**分析所依据的书内章节与理论**

### 2. 按章节逐条（只列本次用到的）
对每一个用到的章节写清：

- **章节名**  
  章节名从 `references/index.json` 的 `chapters` 中取 `title`。
- **用到的书中要点**：  
  - 要点一  
  - 要点二  
  （从该技能的「章节与书中要点」表中选取本次实际用到的。）
- **对应我分析里的**：  
  一两句话说明：在上文分析中哪一段、哪一结论用到了这些要点。
