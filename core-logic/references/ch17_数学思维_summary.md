# 摘要：第 17 章 — 数学思维

数学思维
吴军老师是我特别敬佩的一位老师。他是计算机科学家，是自然语言处理技术的先驱者，是谷歌公司的智能搜索科学家，是腾讯公司的前副总裁，同时也是硅谷著名风险投资人、畅销书作家。
他著有《数学之美》《浪潮之巅》《硅谷之谜》《智能时代》《文明之光》《大学之路》《全球科技通史》《见识》《态度》等，本本都是超级畅销书。我和我儿子小米，都是他的书迷。
同时，他还是教育专家、古典音乐迷、优秀的红酒鉴赏家，酷爱逛博物馆，见过90%以上世界名画的真迹，精通历史、艺术、哲学、摄影、投资、商业……他在任何一个领域的成就单拿出来，都让普通人望尘莫及。
