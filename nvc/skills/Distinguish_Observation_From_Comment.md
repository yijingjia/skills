# Distinguish_Observation_From_Comment

> 基于《非暴力沟通》提取

## 技能描述 (Description)
指导 Agent 在沟通中严格区分客观观察与主观评论，通过提取可验证的具体行为来替代标签化评价，从而降低对方的防御心理。

## 适用场景 (When to Use)
- 自我训练观察能力
- 回应他人时
- 表达感受和需求时
- 全面评估他人时
- 避免混淆事实和意见时
- 表达观点时
- 避免他人产生逆反心理
- 日常沟通练习
- 自我觉察训练
- 职场反馈
- 家庭沟通
- 澄清事实
- 解决内心的冲突时

## 核心思维步骤 (Thinking Steps)

> Agent 必须严格按照以下步骤执行分析框架：

1. **分析输入文本，识别其中是否将观察和评论混为一谈**
   - 📖 *依据 (5)*: 非暴力沟通的第一个要素是观察。将观察和评论混为一谈，别人就会倾向于听到批评，并反驳我们。

2. **扫描并标记句子中的绝对化词语（如总是、从不）及模糊评价性词汇**
   - 📖 *依据 (5)*: 总是、从不等词语在以下句子中表达的是评论。

3. **将识别出的评论替换为特定时间、情境下可验证的具体行为描述**
   - 📖 *依据 (5)*: 模糊的评价性词汇（如太长了、很霸道）属于评论，应替换为可验证的具体行为。

4. **确认最终表述不含静态标签，仅描述动态世界中的具体事实**
   - 📖 *依据 (5)*: 不带评论的观察是人类智力的最高形式，标签会妨碍全面了解一个人
